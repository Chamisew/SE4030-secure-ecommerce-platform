3. Exploit Attempt: Passing Refresh Token as Bearer Token on Protected Resource
--------------------------------------------------------------------------------
Request:
GET /api/v1/orders
Authorization: Bearer <refreshToken>

Response Received:
HTTP Status: 401 Unauthorized
Response Body:
{
  "path": "/api/v1/orders",
  "error": "Unauthorized",
  "timestamp": "2026-09-25T13:30:25.088395Z",
  "message": "Authentication failed: Invalid token type: refresh tokens cannot be used to authenticate API requests",
  "status": 401
}

Result:
Spring Security's JWTFilter verified the token signature, examined the `token_type`
claim, determined it was `refresh` instead of `access`, and rejected the request
with HTTP 401 Unauthorized.
